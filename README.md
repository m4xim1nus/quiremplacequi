# Qui remplace qui ?

Un instrument de mesure des questions démographiques liées aux migrations en
France : combien, depuis quand, à quelle vitesse, qui arrive, qui part, ce que
deviennent les descendants. À partir de données publiques uniquement (Insee,
Ined, statistique publique européenne et internationale), dans la lignée de la
méthode de François Héran. Restitution prévue : site web statique, avec un
module signature, **la piscine** : la population vue comme une eau qui se
renouvelle en permanence.
